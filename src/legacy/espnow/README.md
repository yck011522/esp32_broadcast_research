# Retained ESP-NOW firmware

These are the available evolved master (unicast), master broadcast and OTA
slave sources. Their exact historical revisions for Tests 2–8 are not known.
They are preserved without claiming to recreate missing experiment firmware.

Existing profiles select these relocated folders. The historical `master_radio`
profile remains commented out; `master_radio_broadcast` and `slave_radio_*`
profiles remain available. The historical Test 6 `*_ota` profiles and the
`ble_slave` source are missing. Read each numbered test README before rerunning.
